# Licences and assets

## Bundled preview sample

`public/samples/string-c4.wav` is an original additive-synthesis sample generated for this project by
`scripts/sample.ts`. No recordings, SoundFonts or external sample libraries were used. The sample and
its generation code are dedicated under CC0 1.0 Universal:
https://creativecommons.org/publicdomain/zero/1.0/

It is a synthetic bowed-tone approximation, not a recording of an orchestra. It is bundled locally;
preview never downloads samples from an external service.

`string-low.wav`, `string-mid.wav`, `string-high.wav` and `string-pluck.wav` in the same folder are
additional original additive-synthesis assets generated by `scripts/preview-samples.ts`. They and
that script are also dedicated under CC0 1.0 Universal. Roots are MIDI 36, 60, 72 and 60 respectively.
No external recordings or names are used. The block preview uses these four samples; the original
sample is retained with the Phase 1 assets.

## Development dependencies

Vite, TypeScript, tsx and midi-file are MIT-licensed. @types/node uses the MIT licence. Dependencies and
their exact resolved versions are recorded in package-lock.json; installed licence texts live with
their respective packages in node_modules. No third-party JavaScript runtime dependencies are required
by the arrangement engine. Vite serves local files during development; production app assets are local.

jsdom and @types/jsdom are MIT-licensed development-only dependencies used for the UI smoke test;
they are not shipped as browser runtime code. The interface uses system fonts and Unicode symbols,
with no external font or icon requests.
